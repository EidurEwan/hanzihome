# Characters with more than one reading, in sentences. test/polyphones.js runs each
# sentence through site/textstory.js and checks the reading of the character in brackets.
#
#   sentence with one [character] | the reading it has there
#
# A neutral tone matches any tone of the same syllable (头发 tóu fa for fà): that is a
# question of style, not of which reading. Written by hand, not taken from the stories,
# so the engine has never been tuned on these.
