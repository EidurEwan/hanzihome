# Component rename draft (not wired into the app)

Rule: a component is named for something you can picture. If it looks like something, it is named for that. If its meaning is a thing you can picture (hand, tree, emperor, clay), an adjective (white, sweet, heavy) or a direction (east, left, up), it is named for its meaning. If the meaning is some other abstract word (now, give, because), it keeps a picturable stand-in instead (今 clock, 少 pinch, 正 goal line).

Of the 1066 component names in `site/data/cnames.js`, 121 change. The other 945 already name the shape (丁 nail, 山 mountain, 串 kebab), a picturable meaning (手 hand, 木 tree) or a picturable stand-in for an abstract meaning, so they stay.

The machine-readable list is `cnames-rename.json` next to this file. No two components share a name after the change.

Applying it later also means rewriting each changed component's look note and story, and the 155 component stories and 407 character scenes that name a changed component in *italics*.
